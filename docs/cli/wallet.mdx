  **Phase 3 — Not yet implemented.** Wallet commands are part of the staking roadmap. They exist in the CLI but require the Solana staking program to be deployed.
</Warning>

## oi wallet create

Create a new Solana wallet.

```bash
oi wallet create
```

## oi wallet import

Import an existing wallet from a keypair file.

```bash
oi wallet import <path>
```

## oi wallet balance

Show wallet balance.

```bash
oi wallet balance
```

## oi wallet address

Show wallet public address.

```bash
oi wallet address
```
