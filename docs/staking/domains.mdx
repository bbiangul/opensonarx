  **Legacy/experimental.** These commands may exist in the CLI or devnet substrate, but domain stake is not part of v2.4 ranking or calibrated uncertainty.
</Warning>

## Legacy: stake on a domain

```bash
oi stake rust-lang.org --amount 100
```

## Verify DNS control

Place a TXT record on your domain to create a time-scoped control observation:

```bash
oi domain verify rust-lang.org
```

The CLI will output the required TXT record value. Add it to DNS, then re-run the command to complete verification. DNS control is provenance metadata: it does not prove authorship, licensing, relevance, or factual accuracy and gives no ranking bonus.

## Legacy: unstake

Begin the 7-day cooldown period:

```bash
oi unstake rust-lang.org
```

After 7 days, the tokens are returned to your wallet.

## Retracted: paid curation rank

The legacy command shape was:

```bash
oi domain curate docs.rs --amount 50
```

It must not boost ranking. Any future sponsorship or underwriting is visibly scoped economics and cannot purchase Stage-1 rank or a calibrated posterior.

## Available today

Domain management commands (`oi domain list`, `oi domain info`) show legacy metadata. Existing domain stake does not become OpenUncertainty economic conviction because it lacks an exact claim, direction, horizon, objective outcome, and outcome-specific loss.
