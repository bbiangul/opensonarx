---
title: Feedback (Legacy Telemetry)
description: Submit usefulness telemetry without purchasing or voting on rank.
---

## How feedback works

Feedback records whether a result was useful for a query. It may support offline evaluation, product diagnostics, or a future propensity-aware training dataset. Raw positive/negative counts do not alter Stage-1 rank and do not become a truth or uncertainty label: unauthenticated feedback is Sybil-prone and highly selected.

```bash
oi feedback <result_id> --useful
oi feedback <result_id>          # not useful (default)
```

## With query context

Providing the original query improves the data moat:

```bash
oi feedback r1 --useful \
  --query "rust async programming" \
  --result-url "https://tokio.rs/tutorial" \
  --result-rank 2
```

## View statistics

```bash
oi feedback-stats
```

Shows aggregate metrics: total signals, positive/negative ratio, unique queries, and top helpful domains.

## Impact on ranking and uncertainty

Feedback has no direct ranking multiplier. It can enter a future calibrated model only when the target, sampling/inclusion probability, source and task scope, held-out evaluation, and manipulation controls are declared. Otherwise it remains telemetry.

<Warning>
  Legacy APIs may still expose aggregate reputation or verdict fields. They are not calibrated probabilities and must not be presented as OpenUncertainty output.
</Warning>
