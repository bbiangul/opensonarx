## 1. Install

```bash
curl -fsSL https://opensonarx.com/install.sh | sh
```

Or build from source:

```bash
git clone https://github.com/bbiangul/opensonarx.git
cd opensonarx
cargo build --release --bin oi
```

## 2. Search

Search works immediately — DuckDuckGo blended results are available out of the box, no API keys needed.

```bash
oi search "how to deploy a Next.js app to Vercel"
```

Output includes full content that an LLM can use directly — not just links and thin snippets.

### Output Formats

```bash
# Table (default, human-readable)
oi search "rust async"

# JSON (for piping to jq or feeding to an LLM)
oi search "rust async" -o json

# NDJSON (for streaming)
oi search "rust async" -o ndjson
```

## 3. Seed Your Index

Grow your local index by crawling real content:

```bash
# Spider a site (follow links)
oi seed crawl https://docs.rs --depth 3 --max-pages 500

# Crawl a sitemap
oi seed sitemap https://docs.rs/sitemap.xml

# Top Rust crates from docs.rs
oi seed registry docs-rs --top 100
```

Once seeded, searches return content from your local index — pre-crawled, chunked, and embedded. No page fetching needed.

## 4. Run a P2P Node

Join the decentralized network and expose an HTTP API:

```bash
oi network node --port 4001 --http-port 8001
```

Search through your running node:

```bash
oi search "rust async" --node http://localhost:8001

# Or use curl directly
curl -s -X POST http://localhost:8001/search \
  -H "Content-Type: application/json" \
  -d '{"query": "rust async", "limit": 5}'
```

## 5. Add Better Search Engines

For higher-quality results, add paid engines in `~/.opensonarx/config.toml`:

```toml
[[search.engines]]
name = "google"
priority = 1
api_key = "your-serper-key"

[[search.engines]]
name = "brave"
priority = 5
api_key = "your-brave-key"
```

DuckDuckGo remains as a free fallback at the lowest priority.
