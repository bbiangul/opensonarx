ACT 2  The index is divided by subject, learned from its own content
────────────────────────────────────────────────────────────────────
  No fixed list of topics: the node clusters the pages it holds and writes a routing file.
  The file's version is a hash of its content and becomes part of every shard name.

ACT 3  Two nodes each ingest only their subjects, reading pages once for claims
───────────────────────────────────────────────────────────────────────────────
  Node A serves shard 0, node B serves shard 1. Both are given the same pages.
  Each keeps the chunks of its shard, a model lists what each page states, and a claim
  is stored only if its quote is found character by character in the page.
    node A:  17 chunks kept, 173 claims stored (23 s of fetching and model reading)
    node B:  19 chunks kept, 196 claims stored (24 s of fetching and model reading)
  ✔ PROVED     both nodes extracted and stored claims from the pages of their own shard
               A 173 claims, B 196 claims, 10 pages offered to each, 24 s

ACT 4  A question is answered from stored claims, in milliseconds, across nodes
───────────────────────────────────────────────────────────────────────────────
  No model runs now. The node embeds the question, looks up the nearest stored claims,
  asks the peers whose shards match the subject, and counts independent sources.
  The index does not write an answer: it returns each source in its own words, with the
  quote. Whoever asked, a person or an agent, reads them.

ACT 6  A dishonest node offers a forged claim and the replica refuses it
────────────────────────────────────────────────────────────────────────
  A modified node joins shard 0. It offers a real page with two claims: one sentence
  that is in the page, and one statement it made up, with a quote the page does not contain.
    page          https://www.worldatlas.com/geography/the-10-largest-deserts-in-the-world.html
    honest claim  Deserts are usually considered to be hot, arid areas with vast stretches of sand an…
    forged claim  The Sahara is the largest desert in the world, twice the size of Antarctica.
    forged quote  “The Sahara is the largest desert on Earth, about twice the size of Antarctica.”
    node C: +1 claim stored, +1 refused
  ✔ PROVED     the replica refused exactly the claim whose quote is not in the page
               refused from peers went 0 → 1; the forged statement is not in node C
  ✔ PROVED     the same dishonest node's true claim was accepted
               the honest sentence is in node C, found by its own text
    What this check covers: a quote that is not in the page the replica received.
    A forged page is a different attack; the next act is the check against that.

────────────────────────────────────────────────────────────────────────
